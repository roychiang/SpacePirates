## 技術細節設計
### Auth（VIVERSE，非重導登入）
- 初始化：`globalThis.viverseClient = new viverse.client({ clientId: 'v48pybqy7f', domain: 'account.htcvive.com' })`
- 檢查：`checkAuth()` 於 App 啟動；成功→取得 `{ access_token, account_id, expires_in }`；失敗→`undefined`（guest）。
- 禁止重導：不呼叫 `loginWithWorlds()`；僅被動 `checkAuth()`，保持頁面穩定。
- 錯誤處理：憑證失效時回退至 guest；記錄一次提示，保留 UI 操作。

### Avatar（名稱與頭像）
- 取得 token：若 `checkAuth()` 有憑證則 `getToken()`。
- 客戶端：`avatarClient = new viverse.avatar({ baseURL: 'https://sdk-api.viverse.com/', token })`
- 名稱與頭像：`getProfile()` → `name`、`activeAvatar.headIconUrl`；無頭像或未登入→預設(default)圖像。
- 快取策略：會話生命週期內記憶名稱與頭像，登出或憑證失效時清除。

### Play（Matchmaking/Networking）
- 初始化：`playClient = new viverse.play()`；`matchmakingClient = await playClient.newMatchmakingClient('v48pybqy7f', debug)`。
- Actor 設定：`setActor({ session_id, name, properties })`（session_id 以客戶端生成 UUID）。
- 房間操作：`createRoom({ mode: 'team', maxPlayers: 2, minPlayers: 2 })`、`joinRoom(room_id)`、`leaveRoom()`、`closeRoom()`、`getAvailableRooms()`、`getMyRoomActors()`。
- 事件：若 SDK 提供事件訂閱，監控 `actorJoined/actorLeft/roomUpdated/readyStateChanged`，即時刷新 UI。

### NetSync（沿用本地雙人玩法的遠端同步）
- 策略：輸入驅動 + 重要狀態增量；客戶端預測、以房主權威定期校正。
- 更新節奏：輸入頻率 30–60Hz；狀態增量 10–20Hz；落後或抖動時階梯插值。
- 斷線重連：5s 內恢復；超時則引導回配對頁。

### UI 與元件（沿用現有 Babylon GUI 風格）
- `StatusBar`：`AvatarBadge` 圓形頭像（40px/64px/96px）+ 名稱；字體 `magistral`、主色 `#a6fffa`。
- `QueuePanel`：星塵進度條（`Slider` 主色 `#269ad4`）；等待時間與隊列位置文字。
- `RoomJoinForm`：`InputText` + `menuButton.svg` 按鈕；錯誤 `#af2d0e`。
- `PlayerList/PlayerCard`：圓形頭像（64px）、準備勾 `#05d000`、卡片使用 `textPanel*.svg` 九切。
- `RoomControls`：開始/關閉/離開按鈕遵循主按鈕動效（hover 150ms、click 100ms）。

## 驗證方式
- 本地 Stub 測試（不觸發真 SDK）
  - 提供 `sdk-stubs`：模擬 `checkAuth()`（返回 `undefined` 或假憑證）、`getProfile()`（返回假名稱與頭像）、`newMatchmakingClient()`（返回假房間與演員列表）。
  - 開關：環境旗標 `USE_SDK_STUBS=true` 時啟用；確保行為與真 SDK 介面一致。
- 視覺與互動驗證
  - 手動檢查各頁面元件尺寸/色彩/動效（≤200ms、ease-out）；圓形頭像顯示與 guest 狀態覆蓋。
- 端到端測試（viverse.com）
  - 場景：登入檢查（無重導）、建立/加入房間、準備機制、開始遊戲、結果頁、再玩一次。
  - 失敗情境：憑證失效、房間滿員、斷線重連、超時取消。
- 效能與網路監測
  - FPS 監測：目標 60fps（最低 30fps）。
  - 延遲監測：目標 ≤100ms（可接受 ≤200ms）；顯示於調試面板。
  - 重連時長：≤5s；記錄並上報。
